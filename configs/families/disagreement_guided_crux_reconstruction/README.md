# DGCR

DGCR is an independent test-time inference family. It shares five Stage-A solves with SC5, and on canonical answer-class disagreement compares three independent adaptive resamples against one crux proposer plus two independent, support-blind reconstruction panels. New answers are never eligible for final selection.

Run the live provider audit before the development gate. The held-out phase is blocked unless the exact model and frozen configuration have a passing development gate.
